# Anise Birthday Site 💜💗

## GitHub Pages'e yükleme
1. GitHub'da yeni bir repository oluştur. Örn: `anise-birthday`
2. Bu klasördeki tüm dosyaları repoya yükle:
   - index.html
   - style.css
   - script.js
   - images klasörü
3. GitHub'da repo > Settings > Pages
4. "Build and deployment" altında Source: "Deploy from a branch"
5. Branch: `main`, folder: `/ (root)` seç ve Save'e bas.
6. GitHub sana sitenin bağlantısını gösterecek.
